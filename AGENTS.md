# Hespérides — Fundamentos de Python practice

## Purpose and context

This repository provides Fundamentos de Python classes and practice notebooks for Hespérides. It reuses the teaching organization of the Deep Learning practice project, not its subject content. The [Hespérides corpus](../hesperides/AGENTS.md) holds teaching assignments and source notes.

## Key definitions

- **Student edition:** executable public class material and unsolved practice.
- **Teacher edition:** private solutions, narration and preparation.
- Programming syntax and semantics are subject matter; visual models must reflect actual discrete execution.

## Project map

- [workshop](workshop/): student `clases_sincronas/` and `tareas/`.
- [professor](professor/): private class and exercise editions.
- [professor/resources/documentacion](professor/resources/documentacion/): class sources, concept map and design records.
- `professor/resources/notas/`, `medios/`, `scripts/` and `cache_datos/`: local teaching resources.
- [pyproject.toml](pyproject.toml) and [uv.lock](uv.lock): independent execution environment.
